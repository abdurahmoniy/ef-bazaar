# TgCrypto is deliberately absent. Its last release is 1.2.5 (2022-11-11) and
# it ships wheels for cp37-cp311 only — nothing for the 3.12 this image runs on
# — so pip falls back to the sdist and the build dies for want of a compiler
# that python:3.12-slim does not carry.
#
# Pyrogram treats it as optional: pyrogram/crypto/aes.py catches the ImportError
# and uses pure-Python pyaes instead, warning that it "will work the same, but
# at a much slower speed". That penalty is about bulk transfers. This service
# receives a handful of short notifications a day and sends nothing, so the
# difference is unmeasurable here.
#
# Compiling an abandoned C extension in a multi-stage build would buy speed we
# have no use for, and leave us maintaining it.

aiokafka==0.11.0
