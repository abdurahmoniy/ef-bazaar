# Listing and account completion UX

Approved scope: review improvements 1–5 and 7. Account-card layout (6) is excluded. Owner-only account names remain separate from public descriptions.

Use existing destination pages with dismissible completion notices, resource identity and relevant next actions. Account saves navigate with the saved account ID; this clears conflicting saved filters, highlights and focuses that card. Listings and published accounts receive distinct owner-only messages. Advertising remains optional and follows the listing summary, including creation flows that intentionally selected advertising.

Owners see status, title, price, views and management before the gallery. Buyer instructions, seller profile and similar listings appear in a separate buyer preview or public view. Buyer preview must never allow an owner to contact themselves or mutate buyer state. Public users cannot access owner completion UI via query parameters.

Active owner controls prioritize edit/share. A management disclosure opens an accessible confirmation dialog before marking sold on mobile and desktop. Failures stay visible and pending requests cannot duplicate. Use existing tokens, 44px action targets, wrapping layouts and reduced-motion-aware focus/scroll.

No backend changes, account-name synchronization or account-card redesign.
